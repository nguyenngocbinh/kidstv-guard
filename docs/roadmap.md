# Roadmap

1. M0 Repository and contracts: schema, docs, CI.
2. M1 Quiz Engine: adaptive state machine, remediation, no-repeat selection, serialization and tests.
3. M2 Phone Admin: CRUD, CSV/JSON import, settings and reports.
4. M3 LAN API: SQLite, pairing, auth, incremental sync and offline cache.
5. M4 Tizen TV: remote navigation, quiz UI, lifecycle handling.
6. M5 Timer and cross-app enforcement feasibility spike.
7. M6 Family beta, security hardening and release.

M1 is the first delivery gate. Do not spend time polishing TV UI until engine acceptance tests pass.
